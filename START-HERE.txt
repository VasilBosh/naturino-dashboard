NATURINO DASHBOARD 2.0 — КРАТКИ СТЪПКИ

1. Google таблица → Разширения → Apps Script.
2. Замени целия Code.gs с файла apps-script-Code.gs от този пакет и натисни Save.
3. Презареди Google таблицата.
4. Меню 🌿 Naturino → 🔐 Настрой входа за таблото.
5. Въведи свое потребителско име и парола от поне 10 знака.
6. Apps Script → Deploy → Manage deployments → молив → New version → Deploy.
7. Google таблица → 🌿 Naturino → 4. Обнови статистиката. Изчакай да приключи.
8. В папката на проекта изпълни:

   npm install
   npm run build
   npm run deploy

9. Отвори https://dash.herbabulgaria.bg и влез с новите данни.

ВАЖНО:
- Не изтривай GitHub хранилището или скритата папка .git. Замени само файловете на проекта.
- Файлът public/CNAME пази адреса dash.herbabulgaria.bg при новото публикуване.
- Не изпращай паролата на никого и не я записвай в src/config.js.
- Ако смениш входа от менюто на таблицата, старите сесии спират да работят.
- Подробните инструкции са в README.md.
