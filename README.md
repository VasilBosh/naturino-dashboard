# Naturino Kids — Табло

Уеб табло за клиентската база и напомнянията. Показва статистика и графики и позволява импорт на дневния файл с бутон. Данните живеят в твоята Google таблица; таблото само ги чете и записва.

---

## Какво ти трябва
- Node.js (18 или по-нов) — от [nodejs.org](https://nodejs.org)
- Google таблицата с двигателя (Code.gs), която вече настрои
- Безплатен GitHub акаунт (за хостване)

---

## Стъпка 1 — Пусни проекта локално
Отвори папката в VS Code, после в терминала (Terminal → New Terminal):

```bash
npm install
npm run dev
```

Отвори адреса, който се показва (обикновено `http://localhost:5173`).
Ще видиш таблото с оранжев банер „още не е свързано" — това е нормално, минаваме на стъпка 2.

---

## Стъпка 2 — Свържи таблото с таблицата

### 2а. Добави уеб частта към скрипта
1. Отвори Google таблицата → **Разширения → Apps Script**.
2. Замени целия код с **`apps-script-Code.gs`** (в тази папка). Това е новата версия — има същите напомняния плюс връзка с таблото.
3. Горе в `CONFIG` намери `webToken` и смени `'naturino-taen-kod-smeni-me'` на твой таен код (каквото решиш, само го запомни).
4. Запази.

### 2б. Публикувай скрипта като уеб приложение
1. Горе вдясно: **Deploy → New deployment**.
2. При „Select type" (зъбното колело) избери **Web app**.
3. Настрой:
   - **Execute as:** Me (твоят акаунт)
   - **Who has access:** Anyone
4. **Deploy** → потвърди разрешенията.
5. Копирай **Web app URL** — завършва на `/exec`.

### 2в. Попълни връзката в таблото
Отвори **`src/config.js`** и попълни:

```js
export const CONFIG = {
  API_URL: 'ТУК_ЗАЛЕПИ_URL_КОЙТО_ЗАВЪРШВА_НА_/exec',
  API_TOKEN: 'същият таен код като webToken в скрипта'
}
```

Запази. Таблото се презарежда само и вече показва данните.

> ⚠️ `API_TOKEN` тук и `webToken` в скрипта трябва да са **абсолютно еднакви**.

---

## Стъпка 3 — Качи на GitHub (безплатно хостване)

1. Създай ново хранилище (repository) в GitHub, напр. `naturino-dashboard`.
2. В терминала на проекта:

```bash
git init
git add .
git commit -m "Naturino dashboard"
git branch -M main
git remote add origin https://github.com/ПОТРЕБИТЕЛ/naturino-dashboard.git
git push -u origin main
```

3. Публикувай с една команда (използва пакета `gh-pages`, вече включен):

```bash
npm run build
npm run deploy
```

4. В GitHub: **Settings → Pages** → увери се, че източникът е клон **gh-pages**.
   След минута сайтът е на `https://ПОТРЕБИТЕЛ.github.io/naturino-dashboard/`.

При всяка промяна: `npm run build` и после `npm run deploy`.

> Забележка: `src/config.js` съдържа тайния код и се качва в кода на сайта. Затова дръж хранилището **private**, а тайния код смени, ако смяташ, че е изтекъл (смени го на двете места и публикувай наново).

## Всекидневна употреба
- **Табло** — статистика и графики. Бутонът „Обнови" тегли най-новите числа.
- **Импорт** — пусни дневния файл, натисни „Обработи". Отива в таблицата със същата логика (сравнение по телефон, разпознаване на колони, количество от цената).

Импортът през менюто в самата таблица също продължава да работи — резервен вариант, ако някога уеб импортът засече.

---

## Ако нещо не работи
- **„Данните не се заредиха"** — провери, че `API_URL` завършва на `/exec` и че `API_TOKEN` съвпада с `webToken`. След смяна на скрипта прави **нов** deployment (или „Manage deployments → Edit → New version").
- **Импортът не минава** — увери се, че при публикуването „Who has access" е **Anyone**. Иначе ползвай импорта от менюто в таблицата.
- **Празни графики** — още няма достатъчно данни в базата; направи един импорт.
