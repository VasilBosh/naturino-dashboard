# Naturino Kids — защитено вътрешно табло

Версия 2.0 премахва нестабилното JSONP зареждане и добавя реална защита с потребителско име, парола и 12-часова сесия.

## Какво е променено

- Начална страница за вход с Username и Password.
- Apps Script не връща статистика и не приема импорт без валидна сесия.
- Паролата не присъства във файловете или GitHub. В Apps Script се пази само осолен SHA-256 хеш.
- Старият публичен `API_TOKEN` е премахнат.
- JSONP и динамичният `<script>` са премахнати. Всички операции използват нормален `fetch()` POST с JSON отговор.
- Добавени са автоматични повторни опити при временна мрежова грешка.
- Статистиката се пази в бърз кеш и готова снимка, вместо да се преизчислява при всяко отваряне.
- Импортът има уникален номер и е защитен от повторно изпълнение при прекъсната връзка.
- Запазени са приходите, квотата за имейли, историята на импортите и всички напомняния от версия 8.

## 1. Обнови Apps Script

1. Отвори Google таблицата.
2. Избери **Разширения → Apps Script**.
3. Отвори `Code.gs`, изтрий старото съдържание и постави целия код от файла **`apps-script-Code.gs`**.
4. Натисни **Save**.
5. Върни се в Google таблицата и презареди страницата.

В менюто **🌿 Naturino** вече ще има нова команда:

**🔐 Настрой входа за таблото**

Отвори я и въведи:

- потребителско име с поне 3 знака;
- парола с поне 10 знака;
- повторение на паролата.

Паролата се изпраща само към твоя Apps Script при настройката и се записва като хеш. Винаги можеш да отвориш същото меню и да зададеш нов вход. Това автоматично обезсилва всички предишни сесии.

## 2. Обнови Web App deployment-а

След промяната на `Code.gs` старият Web App продължава да работи със старата версия, докато не го обновиш:

1. В Apps Script избери **Deploy → Manage deployments**.
2. Отвори текущия Web App с иконата на молив.
3. При **Version** избери **New version**.
4. Провери:
   - **Execute as:** Me;
   - **Who has access:** Anyone.
5. Натисни **Deploy**.

Използвай същия `/exec` адрес. Той вече е попълнен в `src/config.js`.

## 3. Подготви статистиката веднъж

След обновяването отвори Google таблицата и избери:

**🌿 Naturino → 4. Обнови статистиката**

Първото преизчисляване може да отнеме около 20–30 секунди. След това обикновеното отваряне на таблото използва готовата снимка и трябва да зарежда бързо.

Бутонът **↻ Обнови** в самото табло прави принудително ново преизчисляване. Импортът и автоматичните напомняния също обновяват готовата статистика.

## 4. Публикувай обновения фронтенд

В терминал, от папката на проекта:

```bash
npm install
npm run build
npm run deploy
```

Ако репото вече е свързано с GitHub, това обновява клона `gh-pages`. В **Settings → Pages** източникът трябва да остане `gh-pages`.

Готовият статичен вариант се намира и в папка `dist` след `npm run build`.

Файлът `public/CNAME` запазва персоналния адрес `dash.herbabulgaria.bg` при всяко ново публикуване. Не го изтривай.

## Всекидневна употреба

- При отваряне първо се показва защитената страница за вход.
- Успешният вход важи 12 часа в конкретния браузър.
- **Изход** изтрива сесията от браузъра.
- **Табло** зарежда последната готова статистика.
- **↻ Обнови** преизчислява данните от таблицата.
- **Импорт** обработва `.xls`, `.xlsx` или `.csv` и веднага обновява статистиката.

## Ако нещо не работи

### „Входът още не е настроен“

Отвори Google таблицата → **🌿 Naturino → 🔐 Настрой входа за таблото**.

### След поставяне на новия Code.gs още работи старото API

Направи **Deploy → Manage deployments → Edit → New version → Deploy**. Самото натискане на Save не обновява публикувания Web App.

### „Временен проблем при връзката с таблицата“

Изчакай няколко секунди и опитай отново. Фронтендът вече прави и автоматични повторни опити. Провери и **Apps Script → Executions** за конкретна грешка.

### Първото зареждане е бавно

Пусни веднъж **🌿 Naturino → 4. Обнови статистиката**. След успешното изчисляване се използва готова снимка.
